How it works
  • Choose a block to revise, then pick a mode — all questions in order, a random selection, or every question across all blocks shuffled at once.
  • After each answer, wrong responses show an explanation drawn from the relevant Notion notes so you can read the source material directly.If you disagree with an answer, or think it is out of scope for Phase 1, please report it with the 'Report Question' feature.
  • Your scores are tracked per lecture, so the summary stats screen shows exactly which topics need the most revision. Please note: This currently only includes CTB, SocPop & VLE - Anatomy pending.
  • Random mode remembers which questions you answered correctly and deprioritises them in your next session, so fresh and previously-missed questions come first — a lightweight spaced-repetition effect.
  • All scores are stored locally in your own browser — nothing is shared. Bookmark https://KristianS9.github.io/Phase1-Quiz/ to always access the latest version.
  • 28/04: Formative questions are now live, some that require images have been stripped out.
